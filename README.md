## ✦ ABOUT ME ✦

*Designing infrastructure. Automating systems. Exploring the Cloud.*

\</div>

Hello! I'm **Dhekra Balbouli**, a third-year Computer Science student at **ISET Bizerte**, specializing in **Networks and Computer Systems (RSI)**.

My interests revolve around network engineering, Linux system administration, infrastructure virtualization, cybersecurity and Cloud/DevOps technologies.

I enjoy understanding how IT infrastructures work, connecting their different components and automating deployment and administration tasks.

### 🎯 My Technical Interests

- 🌐 **Networking:** Routing, switching, VLANs, ACLs, OSPF, NAT and VPN.
- 🖥️ **System Administration:** Linux, Windows environments and network services.
- ☁️ **Cloud Computing:** Virtualization, Azure and infrastructure design.
- 🐳 **DevOps:** Docker, Git, GitHub Actions, Terraform and Ansible.
- 🔐 **Cybersecurity:** Network security, IDS, Snort and SOC fundamentals.
- 🗄️ **Databases:** Oracle and SQL.

## ☁️ CURRENT PROJECT — CLOUD & DEVOPS INFRASTRUCTURE

\<div align="center">

\<img src="[https://capsule-render.vercel.app/api?type=rounded&color=0\:FFF0F5,100\:F8C8DC&height=85&section=header&text=Virtualized%20Cloud%20Infrastructure&fontSize=23&fontColor=8E3158](https://capsule-render.vercel.app/api?type=rounded\&color=0\:FFF0F5,100\:F8C8DC\&height=85\&section=header\&text=Virtualized%20Cloud%20Infrastructure\&fontSize=23\&fontColor=8E3158)" width="90%" alt="Cloud infrastructure project"/>

**Project:** Mise en place d'une infrastructure Cloud virtualisée avec déploiement automatisé d'une application web et supervision centralisée.

Currently developing a local virtualized infrastructure with a possible future migration to a public Cloud platform.

### Architecture & Technologies

| Component                   | Technologies        |
| --------------------------- | ------------------- |
| Virtualization              | VirtualBox / VMware |
| Infrastructure provisioning | Vagrant, Terraform  |
| Network services            | Linux, Bind9        |
| Firewall                    | pfSense             |
| Web server                  | Apache              |
| Automation                  | Ansible             |
| Containers                  | Docker              |
| CI/CD                       | GitHub Actions      |
| Version control             | Git & GitHub        |
| Monitoring                  | Zabbix              |

### Project Objectives

- Build a segmented virtual network infrastructure.
- Automate virtual machine provisioning.
- Configure and manage Linux services.
- Deploy a web application.
- Automate configuration and deployment.
- Establish CI/CD workflows.
- Centralize infrastructure monitoring.
